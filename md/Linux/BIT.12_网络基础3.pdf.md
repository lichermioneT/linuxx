```
1. 内网主机发请求
    主机A:
    192.168.1.10:50000  --->  93.184.216.34:80
2. NAT 路由器改写后发到公网
    路由器改写为:
    202.100.10.5:60001  --->  93.184.216.34:80
    并记录：
    202.100.10.5:60001  <->  192.168.1.10:50000
3. 服务器返回
    93.184.216.34:80  --->  202.100.10.5:60001
4. NAT 路由器查表并还原
    93.184.216.34:80  --->  192.168.1.10:50000
5. 主机A收到返回数据
    整个过程就闭环了。		
    
内网主机访问公网时，网关会执行源地址转换，通常把内网主机的私有 IP 和源端口，映射为网关自己的公网 IP 和一个临时端口，同时在 NAT 表中记录这条映射关系。公网服务器返回数据时，目标地址就是该公网 IP 和端口。NAT 网关收到回包后查询映射表，将数据包的目标 IP 和目标端口还原为原内网主机的地址和端口，再转发回局域网内部，因此回包能够正确返回到发起请求的私网主机。
```
